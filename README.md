# My Budget Tracker

## Project Description

My Budget Tracker is a simple web application that allows users to record and view their expenses. The application was improved using CSS to create a clean, consistent, and user-friendly visual design.

## What I Built

- A Budget Tracker heading and logo.
- An Add Expense form where users can enter an expense name and amount.
- A category dropdown with five categories: Food, Transport, Shopping, Bills, and Entertainment.
- An expense table showing expense name, amount, category, and date.
- JavaScript functionality that adds new expenses to the table when the form is submitted.
- A budgeting tips YouTube video embedded on the page.
- A collapsible "How to use this tracker" section.
- CSS hover effects for table rows and buttons.
- A consistent blue and light-blue color palette throughout the application.
- Google Fonts for improved typography and readability.
- Styled form inputs and buttons with spacing, borders, and rounded corners.
- A styled expense table with a clear header and alternating row colors.
- Visual card sections for the page heading, Add Expense form, and expense table.
- CSS Box Model properties including margin, padding, borders, and border-radius.

## Color Palette

The application uses a simple and consistent color palette:

- Blue for headings, buttons, and table headers.
- Light blue for the Add Expense section and hover effects.
- Light gray-blue for the page background.
- White for the main content cards.
- Dark gray for body text.

## Typography

Google Fonts are used to improve the appearance and readability of the application.

- **Poppins** is used for headings, buttons, and table headers.
- **Roboto** is used for the main body text and form content.

## Styling

The application uses CSS to improve the visual appearance and usability of the Budget Tracker.

The Add Expense form includes:
- Proper spacing and padding.
- Styled input fields and dropdowns.
- Rounded corners.
- Focus effects when users select an input.
- A consistently styled Add Transaction button.

The expense table includes:
- A blue table header with white text.
- Borders around table cells.
- Comfortable cell padding.
- Alternating row colors.
- A hover effect for table rows.
- Rounded corners.

The CSS Box Model is used throughout the page with:
- Margins to separate sections.
- Padding to create space inside containers.
- Borders to define sections.
- Border-radius to create rounded and modern cards.
- Box shadows to create visual separation.

## Files

- `index.html` - Contains the structure and content of the Budget Tracker webpage.
- `style.css` - Contains the visual styling, color palette, typography, table and form styling, hover effects, and CSS Box Model implementation.
- `script.js` - Handles form submission and adds new expenses to the table.
- `README.md` - Explains the project, its features, styling, and files.

## How to Use

1. Open `index.html` in a web browser.
2. Enter an expense name.
3. Enter the expense amount.
4. Select a category.
5. Click **Add Transaction**.
6. The new expense will appear in the expense table.

## Project Goal

The goal of this project is to transform a basic Budget Tracker into a polished and user-friendly application by applying intentional color choices, typography, form and table styling, and the CSS Box Model.
